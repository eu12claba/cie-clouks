# Documents à déposer ici

Déposer les PDF dans ce dossier, avec exactement ces noms :

- `dossier-sortez-les-mouchoirs.pdf`
- `fiche-technique-sortez-les-mouchoirs.pdf`

Les boutons « Dossier » et « Fiche technique » de la page du spectacle
pointent déjà sur ces fichiers.

Tant qu'un PDF est absent, le bouton correspondant se transforme
automatiquement en « — sur demande » et ouvre un email vers
contact@cieclouks.ch. Aucun lien mort n'apparaît sur le site.
